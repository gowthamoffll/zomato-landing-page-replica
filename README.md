# Zomato Clone — Chennai Food Discovery Portal

A pixel-perfect, responsive landing page inspired by Zomato. This project focuses on the food and nightlife scene in Chennai, offering a clean user interface with interactive elements and smooth animations.

## 🚀 Live Demo
[https://gowthamoffll.github.io/zomato-landing-page-replica/]

## ✨ Features

*   **Responsive Design:** Fully optimized for mobile, tablet, and desktop views using CSS Grid and Flexbox.
*   **Real-time Search:** Filter through popular Chennai localities (T.Nagar, Adyar, etc.) instantly as you type in the search bar.
*   **Sticky Navigation:** A smart header that appears as you scroll past the hero section for easy access to login/signup.
*   **Interactive Auth Modal:** Functional Login/Sign Up toggle with form validation and error handling.
*   **Scroll Reveal Animations:** Smooth entrance animations for sections and cards using the Intersection Observer API.
*   **Custom Toast Notifications:** Non-intrusive feedback for user actions like searching or clicking "Coming Soon" links.

## 🛠️ Tech Stack

*   **HTML5:** Semantic structure for better SEO and accessibility.
*   **CSS3:** Custom variables, advanced layouts (Grid/Flexbox), and keyframe animations.
*   **JavaScript (ES6+):** Vanilla JS for DOM manipulation, search logic, and UI interactions.
*   **Fonts:** Playfair Display (Headings) and DM Sans (Body).
